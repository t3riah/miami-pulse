# Miami Pulse — The Local Week

A weekly report of local events in Miami-Dade and Broward, locals first:
street fairs, farmers markets, library programs, and community nights
alongside the arena shows, with a family lens throughout.

The live page is always the current issue. Past issues sit beside it as
dated files (weekly-report-YYYY-MM-DD.html).

This is a site-only public repository. It holds only the generated pages.
The ingestion engine, the event database, and all credentials stay
private on the operator's machine. Each issue is regenerated from that
database; nothing here is hand-typed.

Built with the Grove Golden Hour x Broadsheet design system.
