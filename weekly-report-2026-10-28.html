How this report stays honest

  • One source each. All 515 events in this window come from a single distinct source. 0 have two or more. A listing is only as good as its named source.
  • Library edge. The library feed reaches to 2026-11-04. This window sits inside the feed window.
  • Feed times. 20 listing(s) carried a midnight or 1 a.m. start time in the feed, which usually means all-day or no time given. Those print without a time.
  • Civic meetings. 14 civic/admin items were excluded from the day listings (flag plus committee/board title pattern, which caught 2 the feed had not flagged; library teen advisory programs with 'committee' in the title are not counted here, they stay in the library counts).
  • Ticketmaster is dark. No key in secure storage, so the built fetcher skips it by design. Ticketed inventory here is SeatGeek only (34 events).
  • Weather horizon. Forecasts run to 2026-11-03. Days past that show no weather here, rather than a stale forecast.
  • Blurbs. Each listing carries one or two sentences from its own feed description, HTML stripped and capped. Where a feed had no description, the blurb is built only from category, venue, neighborhood, and price/free status already in the store. Nothing about a performer or program was added from outside the feed.
  • What is missing. Eventbrite's long tail is not in the store, Broward libraries are not probed yet, and monthly markets are held until the recurring layer can express nth-weekday rules. None of that is faked in.
